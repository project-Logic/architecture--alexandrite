Добавление трейсинга в систему компании «Александрит» необходимо для детального отслеживания пути заказов и выявления проблемных мест. Трейсинг позволит:
- Быстро находить и устранять узкие места в процессе обработки заказов.
- Улучшать взаимодействие между компонентами системы.
- Повышать надежность и производительность системы.
- Снижать количество ошибок и задержек в обработке заказов.

### Технические и бизнес-метрики

1. **Время обработки заказа**: Сокращение времени обработки заказов.
2. **Количество ошибок в процессе**: Уменьшение числа ошибок при обработке заказов.
3. **Время простоя системы**: Снижение времени простоя за счет быстрого обнаружения проблем.
4. **Удовлетворенность клиентов**: Повышение уровня удовлетворенности клиентов за счет более быстрого выполнения заказов.
5. **Эффективность работы операторов**: Улучшение эффективности работы операторов за счет более прозрачного процесса.

### Предлагаемое решение

Для реализации трейсинга мы будем использовать OpenTelemetry и Jaeger. Эти технологии позволят собирать и визуализировать трассы запросов через систему. Необходимо внедрить следующие компоненты:
- Интеграция OpenTelemetry в каждый API (Shop, CRM, MES).
- Установка и настройка Jaeger для визуализации трасс.
- Обновление схемы C4 с добавлением компонентов трейсинга.

### Компромиссы

Трейсинг может быть сложен в реализации для проприетарных систем, где нет доступа к исходному коду. Также, внедрение трейсинга может потребовать значительных ресурсов и времени на настройку и оптимизацию.

### Аспекты безопасности

- Внедрение аутентификации: доступ к системе трейсинга будет возможен только для сотрудников с актуальной учетной записью и ролью «Поддержка».
- Шифрование данных: все данные трейсинга будут шифроваться для предотвращения несанкционированного доступа.
- Логирование доступа: все действия в системе трейсинга будут логироваться для последующего аудита.
