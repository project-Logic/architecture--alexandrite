### Мотивация

Добавление мониторинга в систему компании «Александрит» необходимо для обеспечения стабильной работы и быстрого реагирования на возникающие проблемы. Мониторинг позволит:
- Выявлять узкие места и проблемы в реальном времени.
- Улучшать производительность и надежность системы.
- Снижать время простоя и увеличивать удовлетворенность клиентов.
- Поддерживать высокий уровень обслуживания и предотвращать потери контрактов.

### Выбор подхода к мониторингу

Для мониторинга системы мы будем использовать подход «Четыре золотых сигнала», который включает в себя отслеживание задержек, трафика, ошибок и насыщенности. Это позволит получить полное представление о состоянии системы и быстро реагировать на изменения.

### Метрики для отслеживания

1. **Number of requests (RPS) for internet shop API**
   - Зачем: Для оценки нагрузки и производительности интернет-магазина.
   - Ярлыки: endpoint, user_id

2. **Response time (latency) for shop API**
   - Зачем: Для контроля времени отклика и улучшения пользовательского опыта.
   - Ярлыки: endpoint

3. **Number of HTTP 500 for shop API**
   - Зачем: Для выявления ошибок и проблем в работе API.
   - Ярлыки: endpoint

4. **CPU % for MES API**
   - Зачем: Для контроля использования ресурсов и предотвращения перегрузок.
   - Ярлыки: instance_id

5. **Memory Utilisation for MES db instance**
   - Зачем: Для предотвращения нехватки памяти и обеспечения стабильной работы базы данных.
   - Ярлыки: instance_id

6. **Number of dead-letter-exchange letters in RabbitMQ**
   - Зачем: Для контроля за потерянными сообщениями и улучшения надежности очередей.
   - Ярлыки: queue_name

### План действий

1. Создать инстанс time-series базы данных для хранения метрик с использованием Prometheus.
2. Настроить сбор метрик с помощью экспортеров для каждого компонента системы.
3. Разработать дашборды в Grafana для визуализации метрик и мониторинга состояния системы.
4. Настроить алерты для критических метрик, чтобы оперативно реагировать на проблемы.
5. Провести тестирование и оптимизацию мониторинга для обеспечения его эффективности.
